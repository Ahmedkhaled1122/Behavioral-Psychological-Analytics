# Behavioral & Psychological Analytics Dashboard

![Behavioral Analytics Dashboard](dashboard.png)

## 📌 Project Overview
This project features an interactive Power BI dashboard designed to analyze and visualize complex behavioral metrics and psychological indicators. The core objective is to measure the impact of smartphone addiction on psychological distress, overall well-being, and quality of life.

## 🎯 Key Insights & Business Value
Through comprehensive data exploration and visual analysis, a critical insight was uncovered:
* **Socioeconomic Impact:** **Family Income** emerged as the most significant factor influencing both smartphone addiction levels and overall psychological distress among participants. This highlights the deep connection between socioeconomic status and mental well-being.

## 📊 Dataset Description
The analysis was conducted on a multi-variable dataset encompassing various demographic, behavioral, and psychological data points. Key metrics include:
* **Demographics:** Gender, Age, Body Mass Index (BMI), Father/Mother Education Level, Family Income, Only Child Status.
* **Behavioral Metrics:** Daily Screen Time, Average Daily Steps, Average Calories Burned, Exercise Companion.
* **Psychological Scales:** * Smartphone Addiction Scale (Short Version)
  * DASS-21 (Total Psychological Distress, Depression, Anxiety, Stress)
  * Rosenberg Self-Esteem Scale
  * WHO-5 Well-Being Index
  * Self-Determination Theory (Autonomy, Competence, Relatedness)
  * Emotion Regulation Questionnaire (Cognitive Reappraisal, Expressive Suppression)
  * Child and Youth Resilience Measure

## 🛠️ Tools & Technologies Used
* **Power BI:** For building interactive dashboards, data modeling, and creating DAX measures.
* **Data Transformation:** Data cleaning and preprocessing to handle complex psychological scale scoring.
* **Exploratory Data Analysis (EDA):** To identify correlations between lifestyle habits, socioeconomic status, and mental health.
